# Como Fazer o Pagamento Produtivo para Homologação

## Situação Atual

Sua conta do Mercado Pago está na **Etapa 4 de 6** do processo de homologação. Para continuar, você precisa:

✅ **Receber 1 pagamento produtivo** (pagamento real, não sandbox)

## Por Que o Botão Está Desabilitado?

O botão está desabilitado porque:
1. A conta ainda não está totalmente homologada
2. O Mercado Pago está forçando o uso de sandbox até completar a homologação
3. É necessário fazer um pagamento real para ativar a produção

## Solução: Fazer um Pagamento Produtivo

### Opção 1: Pagamento Real Mínimo (Recomendado)

1. **Use um cartão de crédito real** (seu próprio cartão)
2. **Faça um pagamento mínimo** (ex: R$ 1,00 ou R$ 10,00)
3. **Complete o pagamento** no checkout do Mercado Pago
4. **Aguarde a confirmação** - O Mercado Pago identificará automaticamente

### Opção 2: Verificar se o Botão Funciona Após Preencher Todos os Campos

O botão pode estar desabilitado porque faltam campos:

1. **Selecione um cartão** de crédito
2. **Preencha o código de segurança (CVV)** do cartão
3. **Selecione as parcelas** (se aplicável)
4. **Verifique se o botão fica habilitado**

### Opção 3: Usar Cartão de Teste do Mercado Pago (Se Disponível)

Alguns casos permitem usar cartões de teste especiais para homologação:

1. Acesse: https://www.mercadopago.com.br/developers/pt/docs/checkout-pro/test-integration
2. Verifique se há cartões especiais para homologação
3. Use esses cartões para fazer o pagamento produtivo

## Passo a Passo para Fazer o Pagamento

### 1. Acesse o Checkout

1. Vá para a página de pagamento do seu site
2. Selecione um presente
3. Escolha "Cartão de Crédito"
4. Preencha o nome do comprador
5. Clique em "Ir para Pagamento"

### 2. No Checkout do Mercado Pago

1. **Selecione um cartão** (ou adicione um novo)
2. **Preencha o CVV** (código de segurança)
3. **Selecione as parcelas** (se aplicável)
4. **Clique em "Pagar"** quando o botão estiver habilitado

### 3. Após o Pagamento

1. O Mercado Pago identificará automaticamente o pagamento produtivo
2. A etapa 4 será concluída
3. Você poderá continuar para a etapa 5

## Se o Botão Continuar Desabilitado

### Verificar Console do Navegador

1. Pressione **F12** no navegador
2. Vá na aba **Console**
3. Verifique se há erros JavaScript
4. Verifique se há mensagens do Mercado Pago

### Verificar se Todos os Campos Estão Preenchidos

O botão só é habilitado quando:
- ✅ Cartão selecionado
- ✅ CVV preenchido
- ✅ Parcelas selecionadas (se aplicável)

### Tentar com Outro Cartão

1. Tente com outro cartão de crédito
2. Verifique se o cartão está ativo
3. Verifique se há limite disponível

## Verificar Status da Homologação

Após fazer o pagamento:

1. Acesse: https://www.mercadopago.com.br/developers/panel
2. Vá em **Suas integrações** > **Suas credenciais**
3. Verifique se a etapa 4 foi concluída
4. Clique em "Já fiz o pagamento" se disponível

## Importante

- ⚠️ O pagamento deve ser **real** (não sandbox)
- ⚠️ Use um **cartão de crédito real**
- ⚠️ O valor pode ser **mínimo** (R$ 1,00 ou R$ 10,00)
- ⚠️ O Mercado Pago identificará automaticamente após o pagamento

## Próximos Passos Após Homologação

Após completar a etapa 4:

1. ✅ A conta estará homologada
2. ✅ O sandbox não aparecerá mais
3. ✅ Os pagamentos reais funcionarão normalmente
4. ✅ Você poderá continuar para as etapas 5 e 6

Se ainda tiver problemas:

1. Entre em contato com o suporte do Mercado Pago
2. Explique que está na etapa 4 de homologação
3. Pergunte sobre como fazer o pagamento produtivo
4. Informe que o botão está desabilitado
